🔑 GitHub Yetkilendirmesi (Kişisel Token) Token kaydedilmedi

Herhangi bir cihazdan kütüphanenize kitap ekleyip doğrudan GitHub'a kaydedebilmek için repo yetkisine sahip bir GitHub Personal Access Token (PAT) gereklidir. Token'ınız sadece bu tarayıcının yerel hafızasında (localStorage) saklanır, hiçbir sunucuya iletilmez.
